# Indonesia-learning research: public resources and reusable media

Selection principle: prefer institutional/encyclopedic sources and Wikimedia Commons. For Commons media, use the file page (not a copied image URL), read the displayed license/attribution requirements, and retain the author + license in app metadata. Do not assume every item in a category is reusable.

## Topic resources

### Geography
- [Encyclopaedia Britannica — Indonesia](https://www.britannica.com/place/Indonesia) — reputable overview of the archipelago's location, islands, climate, population, and physical geography.
- [CIA World Factbook — Indonesia](https://www.cia.gov/the-world-factbook/countries/indonesia/) — public US-government reference for geography, people, government, and country statistics; useful for fact-checking rather than as a visual source.

### Peoples and languages
- [Encyclopaedia Britannica — Indonesia: People](https://www.britannica.com/place/Indonesia/People) — concise, editorially reviewed overview of Indonesia's ethnic and linguistic diversity.
- [UNESCO — Languages](https://www.unesco.org/en/languages) — authoritative context on linguistic diversity and language vitality; pair with local/community sources when presenting individual Indonesian languages.

### Maritime kingdoms
- [Encyclopaedia Britannica — Srivijaya empire](https://www.britannica.com/place/Srivijaya-empire) — established reference for Srivijaya's maritime trade network, geography, and historical period.
- [UNESCO World Heritage — Borobudur Temple Compounds](https://whc.unesco.org/en/list/592/) — official heritage documentation for a major Central Javanese monument and its historical Buddhist context; suitable for linking maritime-era cultural exchange to a concrete site.

### Religion and adat (customary practice)
- [Encyclopaedia Britannica — Indonesia: Religion](https://www.britannica.com/place/Indonesia/Religion) — editorial overview of Islam, Christianity, Hinduism, Buddhism, and local traditions in Indonesia.
- [UNESCO Intangible Cultural Heritage — Indonesia](https://ich.unesco.org/en/state/indonesia-ID) — official inventory context for Indonesian living heritage; useful entries include wayang, batik, angklung, noken, and traditional dances. Each element page includes its own safeguards/description and should be cited separately.

### Modern history
- [Encyclopaedia Britannica — Indonesia: History](https://www.britannica.com/place/Indonesia/History) — broad timeline from colonial rule and independence through the modern republic.
- [US Department of State, Office of the Historian — Indonesia](https://history.state.gov/countries/indonesia) — official historical-relations overview, useful for post-independence chronology and source triangulation.

## Wikimedia Commons media starting points

These are stable Commons file/category pages or canonical searches. Prefer the file page's original-resolution download and license notice; avoid hotlinking thumbnails.

- [Maps of Indonesia](https://commons.wikimedia.org/wiki/Category:Maps_of_Indonesia) — reusable map candidates for island geography and provinces; filter for SVG/PNG and check each file's license.
- [Indonesia location map.svg (Commons search)](https://commons.wikimedia.org/w/index.php?search=Indonesia+location+map.svg&title=Special:MediaSearch&type=image) — search landing page for location-map files; select the exact file page and record its attribution.
- [Borobudur Temple images](https://commons.wikimedia.org/wiki/Category:Views_of_Borobudur) — large set of site photographs for Buddhist history and Central Java; check individual licenses.
- [Prambanan images](https://commons.wikimedia.org/wiki/Category:Prambanan) — Hindu temple complex photography for religion, architecture, and Java history.
- [Wayang kulit](https://commons.wikimedia.org/wiki/Category:Wayang_kulit) — cultural-performance imagery; especially useful for adat/performing-arts lessons.
- [Indonesian batik](https://commons.wikimedia.org/wiki/Category:Batik_of_Indonesia) — pattern/textile references for living heritage; confirm the particular photograph/pattern file's license and attribution.
- [History of Indonesia](https://commons.wikimedia.org/wiki/Category:History_of_Indonesia) — historical photographs, maps, and documents; use the file page's date/source/license metadata before publication.
- [Indonesia — Wikimedia Commons category](https://commons.wikimedia.org/wiki/Category:Indonesia) — broad source directory for landscapes, culture, and public-domain/CC media.

## Video guidance

For video, avoid embedding random reuploads. Use the [Wikimedia Commons video search](https://commons.wikimedia.org/w/index.php?search=Indonesia&title=Special:MediaSearch&type=video) and select only files whose individual page clearly states a reusable license. For institutional viewing links, use UNESCO's Borobudur documentation above and the UNESCO ICH Indonesia inventory rather than copying third-party documentary footage. If the app needs downloadable video, download only an explicitly CC/public-domain Commons file and preserve its attribution/license in the app.

## Rights checklist

1. Verify the exact file page's license (CC BY, CC BY-SA, public domain, etc.); category membership alone is not a license.
2. Store title, creator, source URL, license URL, and required attribution alongside every asset.
3. Do not crop out attribution where the license requires it; preserve moral-rights/cultural-context notes for community-made heritage imagery.
4. Britannica and government/UNESCO pages are reliable learning references, but their text/images are not automatically app-reusable. Link to them; do not copy their protected media without permission.
